# Frontend

Interfaz React 18 + TypeScript + Vite, con React Router, React Query, Axios, React Hook Form, Zod y Tailwind CSS. Copia `frontend/.env.example` como `frontend/.env` si necesitas cambiar la URL de la API.

Desde `frontend/`, ejecuta `npm install` y `npm run dev`. Para validar, ejecuta `npm run typecheck`, `npm run lint` y `npm run build`.
